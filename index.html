SJF METHOD

Shortest job first

Whenever the line is free, the scheduler looks at the tasks that have already arrived and runs the one with the shortest burst time. A running task is never interrupted.

Scheduling type Non-preemptive
Arrival time Set per task
Priority rule Lowest burst time
Tie-breaker Earlier arrival

ⓘ   About this report

This educational project demonstrates non-preemptive SJF scheduling. Each task has an arrival time; when the line becomes free, the arrived task with the lowest burst time runs to completion. Waiting time = start − arrival, and turnaround time = completion − arrival.
